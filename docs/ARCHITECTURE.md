# BANKFLOW · Архитектура
Единый портал (index.html — переносимый офлайн-бандл) и исходники в src/. Модули 01–07 независимы, общие синтетические CSV и SQL в data/database. SQLite API на Python stdlib обслуживает настоящий поиск; браузер при открытии файла использует встроенный снимок и явно показывает режим. MySQL — отдельная учебная СУБД, Express — отдельный сервер ЛР9, Python/Colab — ИИС. В браузере нет паролей реальной системы, сервер по умолчанию привязан к loopback. GitHub Pages пригоден только для статической сборки. Для локальной сети `python backend/server.py --host 0.0.0.0`; на планшете открыть IP ПК:8000, только доверенная сеть, firewall. Не публиковать исходные документы преподавателей без разрешения.
Каждый модуль имеет собственный README и исходники, можно передать папку вместе с необходимыми общими data/database. Offline HTML не заменяет обязательный запуск соответствующих сред.

## Версия 1.1
- `src/workspace.js`: рабочий контур, личный прогресс, маршруты, офлайн-регистрация.
- `backend/server.py`: GET /api/requests, POST /api/requests, PATCH /api/requests/{id}; проверка внешних ключей и допустимых статусов/приоритетов; параметры SQL, ограничение JSON до 4096 байт и запрет cross-origin записи. Локальная учебная система без авторизации.
- `sw.js` генерируется при сборке: статический кэш по хэшу HTML, API исключён. GitHub Pages — браузерные данные localStorage, не серверная БД. Режимы хранения явно разделены.
- Аналитика ИИС остаётся на неизменяемом учебном наборе, новые обращения не меняют результаты ЛР1.
- Сборка использует пути POSIX и UTF-8, не пишет за пределы проекта; `src/build.py` собирает автономный HTML и комплекты.

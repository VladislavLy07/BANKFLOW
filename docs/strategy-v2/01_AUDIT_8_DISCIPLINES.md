### 1. Базы данных — Блиновская Татьяна Михайловна
**Источник:** индекс «БД_результаты_и_индекс.md» и фото письма от 23 октября 2026; достоверность B. Лабораторные необходимы для первой контрольной точки, можно передать по электронной почте либо лично; точный календарный дедлайн письма не установлен. Некоторые материалы, опубликованные в теме «БД», относятся к ИСиТ и проектированию ИС — их нельзя считать лабораторными по БД.

**В BANKFLOW v1.2:** реально работающий SQLite-демонстратор: поиск 60 синтетических клиентов; связи с продуктами, сотрудниками и заявками; локальный API. SQL-схема и скрипты есть. Это достойное дополнение, но **не подтверждение задания Блиновской**. Access, тема курсовой, количество и вариант официально не зафиксированы. Старые упоминания ЛР9–12 и варианта №10 «вступительные экзамены» учитывать только как гипотезу C до оригинала.

**Доработки:** получить из СКИФ исходное условие каждой ЛР, форму отчёта, обязательную СУБД, номер варианта; создать для каждого пункта прямой контракт «вход → действие → ожидаемый SQL/форма → скриншот → отчёт». Если назначена Access, выполнить отдельный файл `.accdb`, не подменяя его SQLite. Курсовая — самостоятельный пакет со структурой преподавателя.

**Порог сдачи:** оригинал задания, выполнены все назначенные пункты, файл требуемой СУБД, запросы/формы/отчёт, доказательство запуска и явное подтверждение передачи.

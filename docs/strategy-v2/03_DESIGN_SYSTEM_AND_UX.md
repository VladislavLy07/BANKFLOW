# BANKFLOW — редизайн «FINTECH ENGINEERING STUDIO»
**Задача:** поднять визуальное качество, не скрывая академическую достоверность. Визуальная ассоциация: дисциплина и ясность интерфейса корпоративного финтеха, без логотипа или фирменных ресурсов ПСБ и без заявлений об официальной связи.

## Визуальная идея
**Новый облик:** «светлая инженерная консоль с характером» — белый тёплый холст, плотный чернильный navy, яркий оранжевый как акцент действий; точные сетки, типографика уровня редакционного продукта, много воздуха, тонкие линии и глубина только в нужных местах. Никакого избыточного стекломорфизма, случайных градиентов и сотен пёстрых карточек.

## Базовые правила
- **Типографика:** системный sans (в будущем локальный WOFF2 при наличии права использования); крупные числа tabular-nums, заголовки 28–40, карточки 18–20, основной текст 15–16; не менее 14 px на информационных таблицах.
- **Сетка:** desktop sidebar 256 px, содержание max-width 1280 px; планшет landscape 12 колонок; portrait — нижняя панель или компактный drawer, без горизонтального скролла всего приложения.
- **Отступы:** 4/8/12/16/24/32/48; без случайных 17/19/27.
- **Поверхности:** максимум 2 уровня визуальной глубины, тени только для интерактивных слоёв; важные числа без жирных цветных рамок.
- **Доступность:** читабельный контраст, видимый focus, крупные touch-targets, подписи форм, клавиатура, reduced motion, фокус не скрыт при раскрытии панелей (ориентир WCAG 2.2).
- **Движение:** 130–220 ms, без бесконечной анимации, уважать `prefers-reduced-motion`.

## Главные экраны
1. **Overview / Академическая карта.** Сверху три информационных блока: «среды», «готово к показу», «подтверждено требованиями». Не показывать несуществующий процент официальных сдач. Ниже семь IT-дисциплин; восьмая — отдельная карточка учебного плана. Видно, где установлен вариант, где нет.
2. **Subject / Паспорт предмета.** Название, преподаватель, форма контроля, ближайшее подтверждённое действие, таблица ЛР; различать «ТЗ найдено», «требует уточнения», «выполнено локально», «принято» — это разные состояния.
3. **Lab / Виртуальная лаборатория.** Слева условие и checkable критерии, по центру интерактивная работа, справа доказательства и статус; на планшете использовать вкладки. Каждому шагу — код, выход и объяснение.
4. **Demo / Режим преподавателя.** Один тап — fullscreen, скрыть отладку и лишние предметы, оставить конкретный модуль и кнопку «Показать исходники», «Проверить тест», «Скачать комплект».
5. **Data Explorer.** Фильтр клиентов, картина связей SQL, request lifecycle, селекторы по согласованным справочникам, empty/loading/error states, объяснение «это синтетика».
6. **Research Lab.** Графики анализа, статистические подписи, табличная версия графиков, источники датасета, рядом кнопка скачать исполненный Notebook.
7. **Submission / Приёмка.** Список файлов для конкретного преподавателя, проверки выполнения, статусы, место для добровольной рукописной фиксации демонстрации, кнопка отмены. Без подделки официального зачёта.

### Нельзя допускать
- Декоративные кнопки без действия.
- Красивые графики без единиц измерения, источника, периода и подписей осей.
- Показ учебного демо как реального банковского сервиса.
- Непроверенные галочки «готово», «сдано», «принято».
- Реальные логотипы ПСБ, фирменные изображения или корпоративные документы без прав.
- Хранение подписи или чужих имен на публичном GitHub Pages.

## Подпись пером на планшете
По нажатию «Зафиксировать демонстрацию» открыть canvas на весь удобный прямоугольник со стилусом, Pointer Events pressure (если доступно), кнопки «Очистить», «Отменить», «Сохранить локально». При желании вместо подписи — чекбокс «Показано преподавателю лично». Хранить локально (IndexedDB), экспортировать только по явному действию пользователя; рядом предупреждение о неофициальном характере. Зелёный цвет — статус **локальной записи**, не аттестации.

## Конкретные дизайнерские тесты
- Galaxy Tab 16:10 landscape; типовые ширины 390, 768, 1024, 1280; масштаб браузера 200%.
- Тест с пальцем и S Pen: dropdown, скролл, ввод, подпись, отмена.
- Проверка на 100% в светлой и тёмной теме (тёмная опциональна, не раньше core).
- Офлайн после установки PWA: главная, предметы, демонстрации, встроенные исходники; понятный индикатор, почему серверный API недоступен.
- Скриншоты до/после, визуальные регрессионные тесты.

## Графическая система
Иконки — единый контурный набор, одинаковая толщина 1.75/2 px, без смешения эмодзи/растровых иконок. Иллюстрации — собственные векторные схемы, диаграммы данных и wireframes; не брать случайные чужие картинки. В шапке — абстрактный символ маршрутов/узлов BANKFLOW, **не** знак ПСБ. Чертёжные сетки, «data-lines», схемы связей используются дозированно в overview и учебных разделах.

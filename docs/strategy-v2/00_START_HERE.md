# BANKFLOW — пакет стратегического развития
**Версия:** 2.0 / техническое предложение, не выпуск программы  
**Дата аудита:** 17 ноября 2026 г.  
**Объект:** `VladislavLy07/BANKFLOW`, ветка `main`, версия приложения v1.2.  
**Учебный контекст:** ДГТУ, ВОЗПИ-31, осень 2026.

## Главное
BANKFLOW — независимая учебная информационная система обработки обращений в условном банковском подразделении. Приложение объединяет семь IT-дисциплин в едином интерфейсе; восьмая дисциплина — ОФП/СМГ — остаётся отдельной записью учебного реестра. **Никакие реальные банковские данные, секреты или документы работодателя не используются.**

**Цель следующего этапа:** перейти от красивого демонстратора к проверяемой системе сдачи работ: каждое требование преподавателя → точный исходный источник → реализация → автоматическая и ручная проверка → доказательство запуска → отдельный пакет для преподавателя → статус фактической сдачи.

## Что в пакете
1. `01_AUDIT_8_DISCIPLINES.md` — восемь предметов, проверенные задания, пробелы и соответствие BANKFLOW.
2. `02_PRODUCT_AND_ARCHITECTURE.md` — PRD, техническая архитектура, объекты, контракт модулей, безопасность, ограничения.
3. `03_DESIGN_SYSTEM_AND_UX.md` — направление визуального редизайна в эстетике «fintech / PSB-inspired», экраны планшета, компоненты, типографика, доступность.
4. `04_ROADMAP_AND_QA.md` — приоритеты, поэтапная реализация, критерии приёмки и тесты.
5. `05_MASTER_PROMPT_FOR_WORK.md` — **главный гигантский промпт** для автономной последовательной работы, а также генерации и критики специализированных промптов.
6. `06_META_PROMPT_FACTORY.md` — отдельный генератор промптов второго уровня, оценка качества и запрет галлюцинаций.
7. `07_PROMPTS_FOR_8_SUBJECTS.md` — готовые стартовые задания для отдельных тематических чатов.
8. `08_REQUIREMENTS_REGISTER.json` — машиночитаемый реестр найденных работ и неизвестных.
9. `BANKFLOW_Strategy_v2.docx` — краткий печатный дизайн- и архитектурный отчёт для обсуждения.

## Статус достоверности
**Это аудит сохранённых материалов и кода, а не удостоверение преподавателями.** Восемь тематических чатов не были заново целиком прочитаны в этой сессии: использованы доступные исходные методички, ранее сохранённые результаты тематической проверки и актуальные файлы GitHub. Там, где нет точного ТЗ, отмечено «не подтверждено», а не выдумано восемь лабораторных.

## Рекомендуемое применение
Скопировать **весь** `05_MASTER_PROMPT_FOR_WORK.md` в ChatGPT Work с подключённым GitHub. Для глубокого исследовательского прохода приложить `01_AUDIT_8_DISCIPLINES.md`, `08_REQUIREMENTS_REGISTER.json` и доступные оригинальные методички (при наличии прав доступа). После каждого этапа сверять фактический `main`, тесты и статус GitHub Pages; не публиковать отчёты или чужие документы без проверки конфиденциальности.

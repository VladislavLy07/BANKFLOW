# Базы данных — Блиновская Т. М.
Демонстрация BANKFLOW: 60 клиентов, 15 сотрудников, 15 продуктов, 360 обращений. 4 связанные таблицы. Поиск, JOIN, GROUP BY, внешние ключи.
Запуск: из корня `python backend/server.py`, затем http://localhost:8000. SQLite создаётся автоматически. `database/schema.sql`, `database/seed.sql`, `modules/01-databases/queries.sql`. Для преподавателя: подтвердить СУБД, вариант, номера ЛР и курсовую. Данная демонстрация не заменяет Access и назначенный вариант.

## ЛР1: точная последовательность трёх сеансов
Только выделенный локальный MySQL 8, без действующих баз. Имена пользователей и БД `test` предусмотрены учебным примером; убедитесь, что они не используются другими людьми. Пароли в скриптах — исключительно демонстрационные, измените перед использованием. Не запускайте `lab01_access.sql` одним сеансом root.

1. Откройте терминал из корня проекта. Войдите `mysql -u root -p` и выполните `source modules/04-isit/lab01_step1_root.sql` (в MySQL Workbench — отдельное соединение администратора). Сохраните вывод CURRENT_USER и SHOW GRANTS.
2. Закройте соединение. Войдите `mysql -u bf_admin -p`, введите пароль из первого учебного скрипта. Выполните `source modules/04-isit/lab01_step2_admin.sql` **по отдельным блокам**, чтобы успеть зафиксировать создание пользователей, выдачу прав, запрет INSERT, переименование, SHOW GRANTS, отзыв прав и удаление. Сделайте скриншоты фактического результата.
3. Вернитесь под root; выполните `source modules/04-isit/lab01_step3_cleanup_root.sql`, удаляющий только созданного учебного администратора. Базу `test` автоматически не удаляем.
4. ЛР2 и ЛР3 выполняйте на отдельной тестовой БД, сверяйте результаты каждого запроса. В MySQL Workbench запускайте скрипты по выделенным командам, сохраняйте скриншоты.

Проверка выполнения должна фиксировать реальные ответы MySQL. В текущей среде MySQL 8 не установлен; сценарии подготовлены, но факт исполнения не подтверждён.

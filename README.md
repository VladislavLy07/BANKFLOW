# BANKFLOW v1.2 · ДГТУ ВОЗПИ-31
**Учебная демонстрационная система, не банковский сервис.** Все данные вымышлены.

## Версия 1.1
- Рабочий контур: регистрация обращения, выбор исполнителя, изменение статуса, фильтры и CSV. На Pages изменения остаются в этом браузере; локальный Python-сервер сохраняет их в SQLite.
- План сдачи: личные отметки по каждой позиции, экспорт/импорт JSON.
- Прямые ссылки на разделы через hash-маршруты (например `#/iis/demo/0`).
- PWA: после первого успешного онлайн-запуска и установки кэша сайт работает офлайн. API не кэшируется.
- ПИС: исправлена оргструктура до внедрения, три отдельные таблицы и восемь видов обеспечения. Стандартизация: полный календарный план из 17 этапов, расчёт CPM.

## Планшет / офлайн
Открыть [сайт BANKFLOW](https://vladislavly07.github.io/BANKFLOW/) или `index.html` в браузере из локальных файлов. Никаких CDN или интернета. На Android выбрать браузер (Chrome/Samsung Internet); если менеджер файлов не открывает HTML, использовать локальный сервер на ПК в общей Wi-Fi сети.
## ПК / настоящий поиск SQLite
`python backend/server.py` из корня, http://127.0.0.1:8000. Для планшета в одной сети: `python backend/server.py --host 0.0.0.0`, открыть `http://IP_ПК:8000`. Не открывать в публичный интернет.

## Быстрый маршрут демонстрации
1. Открыть `index.html` → Базы данных → поиск «Орлова»; режим локального снимка не равен SQL-серверу.
2. ИИС → исходные / очищенные данные, графики, Notebook и отчёт.
3. Серверные технологии → ЛР1–6 → выполнить каждый пункт; отдельно запустить Express по README.
4. ИСиТ → ЛР1–3, скачать точные 19 SQL-заданий ЛР3; показать реальный запуск MySQL после выполнения.
5. Проектирование → ЛР1–3 и единый проектный документ; стандартизация → календарный план и сетевой график.
6. В каждой дисциплине вкладка «Для преподавателя» даёт отдельный ZIP. Для физкультуры — `docs/08-physical-education.md`.

На Windows можно запустить `START_WINDOWS.bat` (Python должен быть установлен). На Linux/macOS — `./start.sh`. Для сборки после правок: `python src/build.py`. Проверки описаны в `tests/verification.txt`.

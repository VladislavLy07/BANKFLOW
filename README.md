# BANKFLOW v1.0 · ДГТУ ВОЗПИ-31
**Учебная демонстрационная система, не банковский сервис.** Все данные вымышлены.

## Планшет / офлайн
Открыть `index.html` в браузере из локальных файлов. Никаких CDN или интернета. На Android выбрать браузер (Chrome/Samsung Internet); если менеджер файлов не открывает HTML, использовать локальный сервер на ПК в общей Wi-Fi сети.
## ПК / настоящий поиск SQLite
`python backend/server.py` из корня, http://127.0.0.1:8000. Для планшета в одной сети: `python backend/server.py --host 0.0.0.0`, открыть `http://IP_ПК:8000`. Не открывать в публичный интернет.
## Предметы
Семь разделов, карточки лабораторных, рабочие интерактивные демонстрации, исходники и выгрузка файлов. `modules/` — независимые комплекты; `docs/` — аудит, архитектура и физкультура.
- БД: SQLite + SQL, обязательная СУБД и задания не подтверждены.
- ИИС: Notebook/CSV, Python, графики; согласовать датасет.
- ИСиТ: MySQL-скрипты, нужен локальный MySQL 8, вариант контрольной неизвестен.
- ПИС: черновик 3 ЛР, добавить реальные скриншоты аналогов и согласовать тему.
- СИТ: 45 решений ЛР1–6 + дополнительные упражнения и Express ЛР9; исходный приложенный HTML ЛР3 и №7/8/10 уточнить.
- Стандартизация: проектный план и черновик документации; расчёты надёжности по варианту не выполнены.
- ВМИП: демонстрация, задания не установлены.
## GitHub
Репозиторий BANKFLOW создан. Для публичной статической демонстрации использовать отдельную чистую сборку без персональных данных: Settings → Pages → Deploy from a branch → main / root (при наличии доступа к Pages). Статический сайт не выполняет MySQL/Python/Express. Публикацию сайта включить в Settings → Pages.
## Сдача
Не выдавать демо за выполненное обязательное задание. Согласовать варианты, выполнить оригинальные пункты, запустить в требуемой среде, сохранить реальные скриншоты и отчёты.

## Быстрый маршрут демонстрации
1. Открыть `index.html` → Базы данных → поиск «Орлова»; режим локального снимка не равен SQL-серверу.
2. ИИС → исходные / очищенные данные, графики, Notebook и отчёт.
3. Серверные технологии → ЛР1–6 → выполнить каждый пункт; отдельно запустить Express по README.
4. ИСиТ → ЛР1–3, скачать точные 19 SQL-заданий ЛР3; показать реальный запуск MySQL после выполнения.
5. Проектирование → ЛР1–3 и единый проектный документ; стандартизация → календарный план и сетевой график.
6. В каждой дисциплине вкладка «Для преподавателя» даёт отдельный ZIP. Для физкультуры — `docs/08-physical-education.md`.

На Windows можно запустить `START_WINDOWS.bat` (Python должен быть установлен). На Linux/macOS — `./start.sh`. Для сборки после правок: `python src/build.py`. Проверки описаны в `tests/verification.txt`.
